A checklist for database structure updates

schema_migrations records which SQL migration files have already been applied. Its fields are version, checksum and applied_at.

An owner runs python -m app.db.migrate during setup or a schema update. That command checks the checklist, applies pending files and records them. The photo upload and editing endpoints do not call it.

On application startup, the backend validates that the preset catalogue can be read. That validation is separate from running a migration.
